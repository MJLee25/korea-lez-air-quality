# GitHub 공개용 정리본

맨 위 README에서 **Online Resource 2**와 **본문·보충자료 결과 대응표**로 바로 이동할 수 있습니다. 본문 표 1–4, 그림 1–3, 보충표 S1–S12, 보충그림 S1을 모두 보존했습니다. 표 밖의 계절 비교·추가 민감도·전처리 검증 결과도 OnlineResource2의 집계 CSV와 검증 요약에 포함됩니다.

`results/`는 결과를 읽는 공간이고, `OnlineResource2/`는 원고가 지칭하는 코드·집계 결과의 기준 위치입니다. 실행 결과는 별도 폴더에 생성됩니다. 기존 추정/추론 코드를 임의로 바꾸거나 다른 결과로 대체하지 않았습니다.

원자료, 관측소별 자료, IDW/nearest 분석 패널과 심사용 ZIP은 공개본에 넣지 않았습니다. 공개 자료만으로 통계 표·그림 및 계절 비교를 재생성할 수 있습니다. 전체 추정은 별도 심사용 패널 또는 정당하게 확보한 동등 입력이 있어야 실행됩니다. 지도인 그림 1과 설명/근거 표 3개는 원본 결과를 보존했으며, 제공되지 않은 지도 생성 코드까지 재현된 것으로 표시하지 않았습니다.

`paper/manuscript_ema.tex`에는 Code availability와 그에 맞춘 Data availability만 수정했습니다. 향후 공개 주소는 https://github.com/MJLee25/korea-lez-air-quality 입니다. 원문이 공개 분석 패널 제공을 약속하던 부분은 실제 공개 범위인 집계 결과에 맞추었습니다. 교체 문구는 `docs/CODE_AVAILABILITY.md`에 따로 있습니다.

검증 범위와 실제 실행 결과는 `docs/VERIFICATION.md`를 확인하세요. 이 폴더 생성은 GitHub 업로드 또는 출판 완료를 의미하지 않습니다.
