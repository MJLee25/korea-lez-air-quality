# Revised Statements and Declarations

## Code availability

Online Resource 2 supplies the estimation, inference, interpolation-sensitivity, seasonal-comparison, and verification scripts and aggregate results, together with the corrected preprocessing scripts, their provenance, and input requirements. Upon publication, these resources will be deposited in a versioned release of the public repository https://github.com/MJLee25/korea-lez-air-quality. The repository identifies the corresponding materials in its OnlineResource2 directory and provides a manuscript-to-results index and instructions for regenerating tables and statistical figures from the included aggregate outputs. Refitting the models requires the separate review-data package or equivalent lawfully obtained prepared inputs; replaying source preprocessing additionally requires the listed original reconstruction inputs. Original monitoring records and the prepared observation-level panels are not included in the public repository.

## Data availability

Original monitoring observations and station information are available from the AirKorea and KMA sources cited in Materials and methods; annual transport and land-use statistics are available through KOSIS. The corrected analysis panel (release 20260920-re), common-support nearest-station panel, and derived policy-neighbor coordinates are available to editors and reviewers from the corresponding author in the accompanying review-data package. The public repository at https://github.com/MJLee25/korea-lez-air-quality will provide aggregate analysis results upon publication. Original monitoring records and prepared observation-level panels are excluded from the public release; access to and reuse of source inputs remain subject to the original providers' terms. Source locations, input requirements, and checksums are documented in Online Resource 2.
