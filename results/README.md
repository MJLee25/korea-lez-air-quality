`figures/` holds original figure assets, `tables/` holds all numerical and static table sources, and `previews/` shows submitted pages with captions and notes. The main seasonal figure is **Fig3_journal.pdf**. Fig3_seasonal is retained only as an additional historical output.

Beyond the displayed tables, these include all 60 pairwise seasonal comparisons, 5 pooled multiplicity-adjusted tests, all 34 station-validation summaries, the May–June ozone fit, all 131 SDM combinations, and 20 event-study combinations. Source-audit summaries are in [validation_evidence](../OnlineResource2/validation_evidence/).
